# observation-manifest — 观察流水清单

## 用途

记录每一次观察行为的**原始动作与原始结果**（查了什么、用什么 operator/命令、得到什么、花了多少代价），使任何另一个 agent 能原样重放并得到同一结论。不维护它的典型错误：第 4 波重复跑第 1 波已经跑过的检索，以及报告里的证据无法被复现、评审只能选择相信。

## 何时更新

每次观察动作**结束时立刻追加一条**（append-only，不改写历史条目）。波尾不做汇总性补写——补写的记忆不可复现。§8 双出交付时本文件全文作为证据附件。

## 模板

路径：`.omz/research/<slug>/observation-manifest.md`（append-only）

```markdown
# observation-manifest — <slug>

## O-001
- 波次/执行者：W1 / explore#2（agent 类型：omz-librarian）
- 时间戳：2026-09-01T14:22:11+08:00
- 意图：<这次观察想回答什么，一句>
- operator：`Bash grep` | `Explore` | `codegraph_explore` | `WebFetch` | `Read` | `执行验证脚本`
- 命令原文（可复制粘贴直接重放，含 cwd；下面是**形态示例**，实际写入时把占位符换成本次观察的真实 cwd 与参数）：
  ```
  cd <项目根的绝对路径> && grep -rn "<关键词>" <目录>
  ```
- 网络来源（operator 为 WebFetch 时必填）：`<URL>`　访问日期：2026-09-01　抓取形态：<全文 | 摘要 | 失败(状态码)>
- 结果摘要（≤5 行，事实性，不含解读）：<...>
- 原始输出留档：`.omz/research/<slug>/raw/O-001.txt`（超 20 行的输出一律外置，此处只留路径）
- 产生的 claim：C-003（new）｜C-001（补证据 [S2]）｜无
- 代价：`cheap`（<10s 无副作用）｜`moderate`（≤2min 或需装依赖）｜`expensive`（改环境/长跑/需人工）
- 可重放性：`replayable`｜`time-sensitive`（结果随上游变化，附访问日期）｜`one-shot`（环境已变，不可重放，说明原因）
```

## 重放契约（每条观察必须满足）

一条观察合法 = 另一个 agent 只读本条即可复现，具体要求：

1. **命令原文逐字可执行**：含 cwd、含完整参数，禁止 `<同上>`、`类似前面那条`、被省略号截断的命令。
2. **网络来源含 URL + 访问日期**，缺一者该观察不得作为独立来源域计入 `claim-graph.md` 的过门计数。
3. **codegraph_explore 观察额外必填** `projectPath` / `HEAD` / 索引时间；索引陈旧标 `stale` 并记录已回退 Explore（§7.5.3 适配条款）。
4. 结果摘要与原始留档分离：摘要给人读，`raw/O-NNN.txt` 给复现比对；两者不一致时以 raw 为准。
5. 失败的观察**同样必须记录**（含失败输出），它是 `## EXPAND` 里 DEAD END 的证据来源。

## 判定规则

1. **防重复劳动前置检查**：发起新观察前先 grep 本文件的 `命令原文` 与 `意图` 字段；命中已有 `replayable` 条目则直接引用其 id，不重跑。命中 `time-sensitive` 条目且访问日期超过调研启动日则可重跑，新建 id 并在新条目里注明"复查 O-0NN"。
2. **claim 的执行验证证据必须落在这里**：`claim-graph.md` 的 `[X<n>]` 只允许指向本文件的 O-id；无对应 O 条目的执行验证视为不存在，claim 不得 gated。
3. `one-shot` 观察不能单独支撑 gated：需另有 `replayable` 观察或一手来源佐证（否则评审无法复核）。
4. 收敛判定输入：本波新增观察条目中"产生的 claim 为无"的比例达到全部 → 该波无新信息，计入"连续 3 波无新 lead"（§7）。
5. 交付时本文件全文进证据附件；`raw/` 目录一并交付，不得只交摘要。
